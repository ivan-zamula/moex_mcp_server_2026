# Архитектура

Проект состоит из MCP-сервера, MCP-клиента и инструментов для работы
с ISS API Московской биржи.

```text
MCP host/client
      │ stdio
      ▼
src/mcp_server/mcp_app.py
      │
      ├── tools/market.py     обзор рынка и лидеры роста/падения
      ├── tools/stocks.py     котировки, история, информация, дивиденды
      ├── tools/portfolio.py  расчёт стоимости портфеля
      └── tools/moex.py       общий HTTP/XML-доступ к MOEX ISS
```

`mcp_app.py` создаёт `MCPServer`, регистрирует инструменты и запускает сервер
через транспорт `stdio`. Клиент `src/clients/mcp_client.py` запускает
сервер отдельным процессом, устанавливает MCP-сессию, получает список
инструментов и вызывает `get_stock_price`.

Тесты подменяют HTTP-запросы к MOEX и не требуют доступа к сети. Реальный
запрос к ISS выполняется только при запуске инструментов через MCP-клиент.
